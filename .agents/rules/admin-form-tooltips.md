# معيار التوضيح والشرح عند كل حقل في نماذج لوحة التحكم (Admin Form Tooltips & Labels Standard)

قاعدة ملزمة لجميع نماذج إدخال البيانات في لوحة الإدارة (`/admin`):

1. **إلزامية وجود أيقونة التوضيح (Help / Info Icon) عند كل حقل:**
   - في جميع نماذج إدخال وملء المعلومات (مثل: نموذج إضافة منتج، تعديل منتج، إدارة الأقسام، الماركات، اللافتات الإعلانية، إعدادات الشحن، كوبونات الخصم، وغيرها).
   - يجب أن تحتوي تسمية كل حقل (Label) على أيقونة تفاعلية صغيرة مثل `<HelpCircle />` أو `<Info />` بجانب اسم الحقل.

2. **سلوك وتجربة المستخدم (UX Behavior):**
   - عند تمرير مؤشر الفأرة (Hover) على الحواسيب أو النقر باللمس (Tap) على الهواتف والأجهزة اللوحية، يظهر تلميح عائم (Tooltip / Popover) أنيق وواضح.
   - يوضح التلميح للآدمن وظيفة هذا الحقل بدقة، نوع البيانات المطلوبة، أمثلة توضيحية، الأثر في واجهة المتجر، أو القيود التقنية (كالأبعاد الموصى بها للصور أو الصيغ المقبولة).

3. **المكون الموحد المعتمد:**
   - استخدام المكون الموحد `FormLabelWithHelp` من `@/components/ui`:
   ```tsx
   import { FormLabelWithHelp } from '@/components/ui';

   <FormLabelWithHelp
     label="سعر المستحضر"
     required
     htmlFor="price"
     helpText="السعر الأساسي المعتمد بالدينار الجزائري (دج) الذي يدفعه الزبون قبل أي خصم."
   />
   ```
